# 🎓 Student Performance Prediction using Machine Learning

## 📌 Project Overview
This is a beginner-friendly Machine Learning project that predicts whether a student will **Pass or Fail** based on study-related factors such as hours studied, attendance, and previous scores.

The project is built using Python, Pandas, and Scikit-learn.

---

## 🚀 Features
- Load student dataset (CSV file)
- Data preprocessing
- Train Machine Learning model
- Predict student performance (Pass/Fail)
- Calculate model accuracy
---
## 🧠 Technologies Used
- Python 🐍
- Pandas 📊
- Scikit-learn 🤖
- VS Code 💻
